# Framework examples

gitglass is plain DOM — every framework integration is "give it an element,
destroy it on unmount". These are minimal wrappers, not apps.

- [react.md](react.md) — React 18+ (and Next.js client components)
- [vue.md](vue.md) — Vue 3
- [angular.md](angular.md) — Angular 17+ standalone
- [svelte.md](svelte.md) — Svelte 5
- [plain.md](plain.md) — no framework, three lines

Load `dist/gitglass.min.js` + `dist/gitglass.min.css` from your bundler, a
`<script>` tag, or a CDN (jsDelivr serves this repo:
`https://cdn.jsdelivr.net/gh/gdhami-net/gitglass@1.2.0/dist/gitglass.min.js`).
