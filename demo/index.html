Snippet mode — one file, a line range, zero API calls

data-gitglass="gdhami-net/gitglass#gitglass.js:L162-L180" renders just that slice, live from the repo, with real line numbers and a link to the exact lines on GitHub. "whole file" expands in place.

Guided tour — walk a reader through a repo
