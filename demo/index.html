A VS Code-style GitHub repo browser for any static page

One data-gitglass attribute gives you a file tree, tabs and highlighted code, fetched live from GitHub. Read-only, no backend, no build step.

  • 9.9 KB JS, min+gzip
  • 2.4 KB core CSS
  • 0 dependencies
  • 18 themes, all optional

Snippet mode: one file, a line range, zero API calls

      
Add #path:L184-L205 to the repo and gitglass shows just those lines, live from GitHub, with their real line numbers and a link to the exact range. “whole file” expands it in place. Snippets read the raw file only, so they never touch the API limit.

      

      

        

      

    

  


  

    

      
Guided tour: walk a reader through a repo

      
Put a JSON script inside the host element. Each step opens a file, highlights a range of lines and explains it. ← and → step through while the viewer has focus.

    Narrow container
    
        
    The same viewer in a 420 px column. gitglass measures its own container, not the window, so it adapts inside sidebars, cards and phone layouts alike.
    
        
      
          
    • Under 720 px of container width the file tree folds behind the ☰ button and opens over the code.
      • 
          
    • Picking a file closes it again. Tabs get narrower, and scroll arrows appear when they overflow.
      • 
          
    • The ⛶ button still takes the viewer full screen; Esc brings it back.
